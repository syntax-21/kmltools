Rename Nama Secara Massal

Tool ini dibuat khusus untuk mengganti nama secara massal tanpa backend. Cocok untuk KML, KMZ, CSV, TXT, dan Excel dengan kombinasi prefix, suffix, find/replace, template nama, serta nomor urut otomatis.

KML / KMZ / CSV / TXT / Excel Rename Bertahap Sequence Otomatis
Mode Rename Nama diproses secara lokal di browser

Untuk file KML/KMZ, tool ini akan mengganti elemen <name> di setiap Placemark. Untuk CSV dan Excel, kolom name akan diperbarui.

Aturan rename

Gunakan {name} untuk nama hasil sementara, dan {n} untuk nomor urut. Jika template kosong, hasil rename akan memakai kombinasi cari/ganti, mode huruf, prefix, dan suffix saja.

Cara Pakai

Alur yang paling aman

1. Upload file sumber

Pilih file KML, CSV, atau TXT yang memuat nama-nama yang ingin diubah secara massal.

2. Atur pola rename

Pakai kombinasi cari/ganti, prefix, suffix, mode huruf, atau template akhir sesuai kebutuhan.

3. Cek preview

Periksa hasil di tabel preview sebelum Anda mengunduh file akhir.

Perilaku Format

Apa yang akan diubah tool ini

KML

Semua elemen Placemark > name akan di-rename sesuai urutan kemunculan di file.

CSV

Kolom name wajib ada. Kolom lain akan tetap dipertahankan seperti semula.

TXT

Setiap baris non-kosong dianggap sebagai satu nama yang bisa diubah secara massal.

Contoh template

ODP-{n}
{name}-REV
AREA-A | {name}
NODE-{n} | {name}
