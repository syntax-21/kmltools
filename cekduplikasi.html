Alur Kerja

Cara Komparasi Master & Bahan

  1. Upload File A (Master): Data acuan utama jaringan/tiang/ODP.
  2. Upload File B (Bahan): Data survey atau data terpasang.
  3. Tentukan toleransi jarak (0m untuk koordinat persis sama).
  4. Sistem secara default memilih Titik Master yang TIDAK Duplikasi untuk dibuatkan placemark baru.
  5. Pilih ikon, ukuran ikon, dan template nama untuk placemark baru.
  6. Klik Komparasi & Insert Placemark. Placemark baru akan langsung disisipkan pada koordinat titik master yang belum ada di bahan.
Keunggulan

Struktur Master Tetap Utuh

Jika File Master berupa KML/KMZ lengkap (berisi jalur kabel, tiang, polygon, dan style bawaan), tool ini akan mempertahankan seluruh isi file master asli dan menyisipkan folder placemark baru tepat pada titik koordinat Master.
