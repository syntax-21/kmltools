Cara Pakai

Alur Urutan Visual Klik

1. Unggah File KML / KMZ

Unggah file kerja yang memuat placemark tiang dan ODP Plan yang ingin diberi nomor urut.

2. Atur Format Nama

Sesuaikan isian form seperti kode ODC, Label, Nomor Awal, Owner, dan jumlah digit nomor.

3. Klik Tiang di Peta

Peta akan memuat tiang (hijau) dan ODP (nomor biru). Klik tiang secara berurutan sesuai rute asli di lapangan.

4. Unduh Hasil

Periksa hasil perubahan pada preview tabel di bagian bawah, lalu unduh KML baru yang sudah rapi.

Perilaku Format

Format Penulisan

Label tiang akan diubah pada tag <description> dengan format:

ODC-LABEL-NNN-OWNER

Contoh: BNL-FAL-001-TLKM

* ODP Plan ditampilkan sebagai kotak biru besar agar memudahkan navigasi urutan klik dari tiang 1 ke tiang berikutnya.
