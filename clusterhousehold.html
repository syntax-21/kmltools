Alur

Cara kerja

  1. Upload master household KML/KMZ yang berisi titik pelanggan atau rumah.
  2. Upload file polygon area, bisa satu file atau banyak file sekaligus.
  3. Klik Proses Cluster untuk menghitung titik yang masuk tiap polygon.
  4. Download ZIP KML untuk hasil per area dan Excel untuk rekap.
Catatan

Batasan versi web

  • Spatial join mengikuti konsep tool Python: titik hanya masuk jika berada di dalam/intersects polygon.
  • Point yang masuk lebih dari satu polygon akan ikut tercatat di semua polygon tersebut, seperti hasil spatial join.
  • Output KML dibuat ulang berisi folder POLYGON dan HOUSEHOLD.
  • Untuk file sangat besar, proses tergantung kemampuan perangkat pengguna.
